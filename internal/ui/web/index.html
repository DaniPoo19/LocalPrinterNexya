¿Cómo funciona la impresión automática con BusinnesAdmin?

Este agente escucha en el puerto local 18181. Cuando en el panel web se confirma un pedido nuevo o se finaliza una venta, la orden se envía instantáneamente a este programa, imprimiendo directo al Spooler de Windows con corte automático de papel sin mostrar ningún diálogo del navegador.
